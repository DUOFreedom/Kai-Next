# 前端开发技能包

当用户要求网页/组件开发时使用本技能。

## 规范
- 优先使用 Tailwind CDN 单文件交付
- 组件命名 PascalCase
- 交付前用浏览器自检渲染效果

## 常用模板
- 落地页：hero + features + footer 三段式
- 数据面板：sidebar + grid 卡片

## 交付示例（单文件 HTML）
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <script src="https://cdn.tailwindcss.com"></script>
  <title>页面标题</title>
</head>
<body class="bg-gray-50">
  <!-- 在此处写内容 -->
</body>
</html>
```
